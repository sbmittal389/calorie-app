# Calorie Counter (PWA + GitHub storage)
1. Private repo `calorie-data` (add a README).
2. Public repo `calorie-app`: upload the contents of ./calorie-app, enable Pages from main.
3. Run ./calorie-data-token-generator.sh to create a scoped token (Contents read/write, this repo only).
4. Open https://<username>.github.io/calorie-app/ in Safari > Share > Add to Home Screen.
5. In the app Settings paste: username, repo, token, USDA key (api.data.gov/signup), goals.
Security: enable 2FA, no collaborators, token expiry, revoke if phone is lost.
